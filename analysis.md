# Анализ предметной области

## 1. Выписанные существительные (кандидаты в классы)
Из текста заказчика выписаны следующие существительные:
книга, ISBN, автор, название, читатель, человек, библиотека, полка, список книг.

## 2. Отбор кандидатов
Из списка кандидатов я выделил две главные сущности: Книга (Book) и Библиотека (Library).
Остальные слова — это либо атрибуты книги (ISBN, автор, название), либо объекты, которые в текущей задаче не играют самостоятельной роли (полка, список книг).

## 3. Класс Книга (Book)
**Атрибуты (что знает):**
- isbn (уникальный номер)
- author (автор)
- title (название)
- isAvailable (доступна или выдана)

**Поведение (что умеет):**
- выдаваться (менять статус на «выдана»)
- возвращаться (менять статус на «доступна»)
- сообщать свой текущий статус (свободна/занята)

## 4. Класс Библиотека (Library)
**Атрибуты (что знает):**
- books (список всех книг)

**Поведение (что умеет):**
- добавлять новую книгу в список
- выдавать книгу читателю (с проверкой, что она свободна)
- принимать книгу обратно (возврат)
- показывать список всех книг
- показывать только доступные книги
- показывать только выданные книги

## 5. Инварианты (утверждения, которые всегда истинны)
1. ISBN каждой книги уникален (в библиотеке нет двух книг с одинаковым номером).
2. Книга не может быть одновременно выдана и доступна.
3. Нельзя выдать книгу, если она уже выдана (это должно вызывать явную ошибку).
4. Нельзя вернуть книгу, которая и так находится на полке.

## 6. Открытые вопросы
Нужен ли отдельный класс «Читатель» (User)? 
Сейчас по условию читатели не различаются. Однако, если в будущем потребуется фиксировать, кто именно взял книгу (должники, история выдач), этот класс обязательно придется добавить.
